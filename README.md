# text-classifier
## Описание
Pet-проект: классификация текстов по темам с помощью классических алгоритмов машинного обучения. Датасет — 20 Newsgroups (встроен в scikit-learn), 4 категории: медицина, космос, хоккей, компьютерная графика.

## Что делает проект
1. Загружает и предобрабатывает тексты (убирает заголовки, подписи, цитаты)
2. Разбивает данные на train/test
3. Превращает тексты в числовые признаки через TF-IDF
4. Обучает и сравнивает две модели — Logistic Regression и Naive Bayes
5. Проверяет обученную модель на собственных примерах вне датасета

## Результаты
- Logistic Regression: accuracy 0.90
- Multinomial Naive Bayes: accuracy 0.90, но с другой структурой ошибок (подробности в ноутбуке)

## Стек
Python, scikit-learn, TF-IDF, Logistic Regression, Multinomial Naive Bayes
